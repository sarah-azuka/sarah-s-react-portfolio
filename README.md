# Sarah Azuka React Portfolio

## Run locally

1. Copy your portrait image into `public/_PVI3080.JPG`.
2. Run `npm install`.
3. Run `npm run dev`.

## Publish with Render

1. Create a GitHub repository and upload this project.
2. In Render, select **New +** then **Static Site**.
3. Connect the GitHub repository.
4. Use build command: `npm run build`.
5. Use publish directory: `dist`.
6. Click **Create Static Site**.
